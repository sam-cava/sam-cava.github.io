📚 Books Collection

Web application full-stack per la gestione avanzata di una libreria personale.

Overview

Books Collection è un progetto pensato come caso di studio enterprise-style, con attenzione a architettura, qualità del codice, sicurezza e manutenibilità. Non è una semplice CRUD app: l’obiettivo è dimostrare competenze reali full-stack.

Architettura

Il progetto segue una struttura layered: 

Frontend Angular SPA
        │
        ▼
Backend Spring Boot REST API
        │
        ▼
Database PostgreSQL

I layer principali:

  • Controller: gestisce le richieste REST
  • Service: contiene la business logic
  • Repository: interagisce con il DB via JPA/Hibernate
  • DTO: isolano il dominio dal frontend

Stack Tecnico

  • Java 21, Spring Boot 3
  • PostgreSQL
  • Angular SPA con routing feature-based
  • JWT per autenticazione e gestione ruoli
  • Docker per sviluppo e testing locale

Caratteristiche principali

  • CRUD avanzato per libri e categorie
  • Ricerca e filtri avanzati
  • Gestione ruoli USER/ADMIN e sicurezza JWT
  • Validazione input e gestione centralizzata errori
  • Frontend modulare e riusabile con componenti Angular
